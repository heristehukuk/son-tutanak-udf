# Son Tutanak UDF Web v6
Build: pip install -r requirements.txt
Start: uvicorn app.main:app --host 0.0.0.0 --port $PORT

Jinja2 kaldırıldı; sayfalar doğrudan HTML olarak oluşturuluyor.
UDF yükleme, otomatik bilgi çıkarma, mobil düzenleme, Anlaşma/Anlaşamama ve UDF oluşturma bulunur.
Dosya boyutu kontrolü ve kalıcı dosya depolama yoktur.
Elektronik imza üretmez veya yenilemez.
